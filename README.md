# 桌面雜物辨識與分類整理小幫手 

> 一個結合 AI 視覺辨識概念與生活實用邏輯的 Python 書桌整理輔助工具。

---

## 💡 開發動機
受到2026臺灣國際AI設計應用博覽會中「AI 視覺辨識與智慧機器人」的啟發，發現 AI 能夠透過鏡頭有效解決現實生活中的引導與辨識問題。因此想將這個概念縮小，運用在學生的日常生活中，解決書桌總是雜亂無章的痛點。

---

## ✨ 系統功能
- **影像載入驗證**：利用 `Pillow` 套件自動讀取並檢驗相機拍下的書桌照片。
- **雜物自動分類**：預設文具、書籍、垃圾等分類邏輯庫。
- **個人化整理建議**：根據辨識結果，自動輸出「收進抽屜」、「放回書架」或「丟進垃圾桶」等具體行動指令。

---
