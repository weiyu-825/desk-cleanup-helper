# 桌面雜物辨識與分類整理小幫手

---

## 1. 專題動機（來自這次展覽的啟發）
在參觀 **2026 臺灣國際 AI 設計應用博覽會** 時，我深受現場展示的「AI 視覺導引智慧機器人系統」啟發。展覽中的機器人能透過鏡頭感知環境並自主進行物件分類，這讓我思考如何將「視覺感知 + 自動分類」的核心概念運用在日常生活中。

身為學生，我常常在讀書後留下滿桌雜物。因此我開發了這個專題，希望透過相機拍下書桌照片，讓電腦自動驗證照片、辨識物品，並給出精準的收拾與歸位建議。

---

## 2. 系統功能
- **影像載入與驗證**：利用 `Pillow` 套件讀取拍下的書桌照片，自動檢驗影像檔案格式與尺寸。
- **雜物分類對照庫**：建立文具、書籍、廢棄物等物品對應的收納邏輯庫。
- **自動整理建議**：根據辨識結果，自動輸出「收進抽屜」、「放回書架」或「丟進垃圾桶」等具體歸位指令。
