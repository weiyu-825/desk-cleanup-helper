# Desk Cleanup Helper (AI 桌面雜物辨識小幫手)

## 1. 專題動機
受到 2026 臺灣國際 AI 設計應用博覽會中「AI 視覺辨識與智慧機器人」的啟發，發現 AI 能夠透過鏡頭有效解決現實生活中的引導與辨識問題。因此想將這個概念縮小，運用在學生的日常生活中，解決書桌總是雜亂無章的痛點。

## 2. 功能與運作流程
* **輸入**：透過 Python 呼叫電腦鏡頭抓取桌面畫面。
* **AI 處理**：使用 OpenCV 與影像辨識邏輯分析畫面中的物件。
* **輸出**：在終端機印出辨識結果與分類建議（例如提醒哪裡需要整理）。

## 3. 使用工具
* Python
* OpenCV (`cv2`)

## 4. 我卡住的地方與解決方法
* **卡住的地方**：一開始不知道怎麼用純 Python 順利叫出筆電的內建鏡頭來抓取畫面。
* **解決方法**：上網查閱 OpenCV 的 `cv2.VideoCapture(0)` 語法，並加入按鍵觸發機制，成功讓畫面即時呈現並能手動觸發辨識。
