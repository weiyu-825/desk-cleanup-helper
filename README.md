# 桌面雜物辨識與分類整理小幫手 

---

## 1. 專題動機
在參觀 **2026 臺灣國際 AI 設計應用博覽會** 時，我深受現場展示的「AI 視覺導引智慧機器人系統」啟發。展覽中的機器人能透過鏡頭感知環境並自主進行物件分類，這讓我思考如何將「視覺感知 + 自動分類」的核心概念運用在日常生活中。

身為學生，我常常在讀書後留下滿桌雜物。因此我開發了這個專題，希望透過相機拍下書桌照片，讓電腦自動驗證照片、辨識物品，並給出精準的收拾與歸位建議。

---

## 2. 系統功能
- **影像載入與驗證**：利用 `Pillow` 套件讀取拍下的書桌照片，自動檢驗影像檔案格式與尺寸。
- **雜物分類對照庫**：建立文具、書籍、廢棄物等物品對應的收納邏輯庫。
- **自動整理建議**：根據辨識結果，自動輸出「收進抽屜」、「放回書架」或「丟進垃圾桶」等具體歸位指令。

---

## 3. 怎麼執行

### 步驟一：安裝必要套件
開啟命令提示字元 (CMD)，執行以下指令：
```bash
pip install Pillow
```

### 步驟二：放置測試照片
將一張書桌照片命名為 `desk.jpg`，放進與程式檔 `main.py` 相同的資料夾中。

### 步驟三：執行程式
在 CMD 中切換至該資料夾，並執行：
```bash
python main.py
```

## 4. 我卡住的地方 ＋ 怎麼解決的紀錄

在開發這個專題時，我遇到了初學者第一次接觸 Python 時常見的系統環境問題：

### 1. 指令列找不到 Python 與 `pip`（環境變數 PATH 問題）
* **卡住狀況**：在 CMD 輸入 `pip install Pillow` 時，系統跳出 `'pip' 不是內部或外部命令`。
* **原因分析**：安裝 Python 時沒有將執行檔路徑自動寫入 Windows 的 PATH 環境變數中。
* **解決方式**：透過 Windows 配置引導將 Python 指令目錄寫入 PATH，並徹底關閉舊 CMD 視窗、開啟全新 CMD 讓變數生效，順利解決套件下載問題。

### 2. Windows 檔案長路徑限制 (Long Path Support)
* **卡住狀況**：設定時跳出 `Windows is not configured to allow paths longer than 260 characters` 警告。
* **解決方式**：在系統提示中輸入 `y` 授權解除 260 字元長度限制，避免未來引入大型 AI 影像辨識套件時因資料夾結構太深而導致報錯。
