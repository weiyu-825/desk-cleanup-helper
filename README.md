# 桌面雜物辨識與分類整理小幫手 

> 一個結合 AI 視覺辨識概念與生活實用邏輯的 Python 書桌整理輔助工具。

---

## 💡 開發動機
在參觀 **2026 臺灣國際 AI 設計應用博覽會** 時，我深受現場展示的「AI 視覺導引智慧機器人系統」啟發。展覽中的機器人能透過影像感知環境並自主解決問題，讓我思考如何將這種「AI 感知 + 實體互動」的核心流程帶入日常生活中。

身為高中生，我常在讀書或打遊戲後留下滿桌雜物。因此，我開發了這個專題，希望透過相機拍照，讓電腦自動辨識桌面上的物品，並給出精準的收拾與歸位建議。

---

## ✨ 系統功能
- **影像載入驗證**：利用 `Pillow` 套件自動讀取並檢驗相機拍下的書桌照片。
- **雜物自動分類**：預設文具、書籍、垃圾等分類邏輯庫。
- **個人化整理建議**：根據辨識結果，自動輸出「收進抽屜」、「放回書架」或「丟進垃圾桶」等具體行動指令。

---
